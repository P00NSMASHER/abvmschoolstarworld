# Yahoo Mail → ABVM weekly reminders

The scheduled workflow `.github/workflows/import-yahoo-weekly-reminders.yml` checks the Yahoo inbox four times per day in America/New_York. It looks for mail from `mthompson@assumptionbvmschool.net` whose subject mentions weekly reminders. It follows only SchoolMessenger PDF links labeled `Weekly Reminders for Week of MM.DD.YY.pdf`; it never follows the Gift Card Winners link. A PDF contributes only fixed school event labels with a verified weekday and date. Unexpected content fails the run for manual review. The original email, tracking URL, PDF, and full extracted text are not committed.

The script adds provenance hashes and an explicit **automated** PII screening receipt to `pages/data/uploaded-notices.json`. The workflow runs the existing integration and validation, then publishes the updated pack and deploys Pages. A previously integrated week is skipped, so enabling the job will not duplicate the October 5 notice.

## Credentials

Open the repository's **Settings → Secrets and variables → Actions → New repository secret**. Use one of these methods:

| Method | Required repository secrets |
| --- | --- |
| Yahoo-generated app password (simplest) | `YAHOO_MAIL_ACCOUNT` = full Yahoo email address; `YAHOO_APP_PASSWORD` = password generated by Yahoo for this integration |
| Yahoo OAuth `mail-r` | `YAHOO_MAIL_ACCOUNT`, `YAHOO_OAUTH_CLIENT_ID`, `YAHOO_OAUTH_CLIENT_SECRET`, `YAHOO_OAUTH_REFRESH_TOKEN`, `YAHOO_OAUTH_REDIRECT_URI` (exactly the registered callback URI) |

An arbitrary 32-character connector API secret is **not** a Yahoo app password or OAuth refresh token. Do not paste any credential in chat, source files, workflow inputs, or Actions logs. An app password can be generated in Yahoo Account Security → External connections → Create app password. OAuth requires a Yahoo Developer Network application with Mail Read access and a one-time authorization code exchange. The ChatGPT Yahoo Mail connection does not expose a reusable token to GitHub Actions.

After setting the secrets, run **Actions → Import ABVM Yahoo weekly reminders → Run workflow**. Check that it reports either `Imported 0 new weekly reminder PDFs` or a successful verified publication. The scheduled runs start automatically once this workflow is on `main`. A Yahoo credential or PDF layout failure fails the job without changing the public app.

GitHub's schedule is best-effort. The four daily checks are timed before or near the existing teacher-page refreshes. New supported events become available after a successful run and Pages deployment; arrival itself does not cause an immediate webhook.
