# Study library scope and note cards

This week uses America/New_York Monday–Sunday boundaries. A download, source check,
archive capture timestamp, or generic pack week label is not evidence of a lesson date.
Dated test events select only matching governed skill families. Dated schoolwork and
archive notes require an explicit studiedOn or weekOf within the displayed week.
Undated and older teacher material remains in Cumulative. When no dated evidence
exists, show an honest empty weekly selection rather than historical fallback.

Topic notes use exact source/pipeline associations. Compact runtime packs retain
noteTopics so full and runtime selections agree after every refresh. Unscoped notes
remain in a Class notes bullet card inside their own subject, without guessing a
chapter. Both scopes use the same renderer, bullet lists, and subject containment.
Original source data and history are retained; duplicate bottom note displays are removed.
Publisher review links stay below Religion notes and must match a selected chapter.

Regression gates: study-notes-scope.test.mjs, study-materials.test.mjs,
runtime-pack.test.mjs, study-notes-library.test.mjs and study-notes-library.spec.mjs.
Full QA, independent reproduction and rendered phone/tablet review remain release gates.
Teacher/homework refresh workflows and schedules are unchanged.
