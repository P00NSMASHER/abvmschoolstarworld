# ABVM Study Ranks

Study Stars now lead through a permanent school-themed rank ladder. Today shows the current rank; Study shows the next promotion; Progress presents the complete ladder. Original polished navy-and-gold emblem artwork lives in `pages/assets/badges` with generation prompts recorded alongside it.

| Rank | Saved stars required |
| --- | ---: |
| Eaglet | 0 |
| Star Scout | 50 |
| Bright Spark | 150 |
| Junior Scholar | 300 |
| Honor Eagle | 600 |
| Golden Eagle | 1000 |
| ABVM Legend | 1500 |

Completed rounds earn the existing 10-star completion reward, up to 10 additional correct-streak stars, and a 25-star bonus when every scored primary question is correct on the first response. Retry success does not qualify for the perfect-round bonus. Hints do not deduct stars; existing independent-learning evidence still records their use.

Every submitted wrong answer deducts up to 2 saved stars immediately, including support and comeback questions. The balance stops at zero. Durable per-attempt identifiers prevent duplicate charges, and completion waits for pending deductions. Leaving a round does not undo a saved deduction. Playful feedback jokes about the answer, never the learner or their intelligence.

Promotions remain earned after deductions. IndexedDB transactions update the existing signed reward ledger and permanent rank achievements together. Legacy migrations use the proven net balance, preserve every existing ledger row, and never fabricate a historical promotion date. A canceled positive/negative reward pair cannot unlock a rank. Rank dates, balances, and progress stay on the device; no learner performance is added to the public repository.

The rank UI is bundled into existing presentation assets to retain the mandatory offline-shell budget. Six optimized transparent 384px WebP emblems total approximately 156 KB and are optional offline artwork. Existing school data, import pipelines, question priority, score evidence, calendar, and provenance gates are unchanged.
