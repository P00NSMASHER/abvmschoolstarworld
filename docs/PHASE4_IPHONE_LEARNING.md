# Phase 4 — iPhone learning, scratch practice, and local history reliability

**Scope:** Existing current-source curriculum, scoring, spaced review, teacher-test practice,
awards, and app publication workflows are unchanged.

- Show a 0–20 tactile counting board only for original Math subtraction questions with
  source-scoped numeric operands 0–20. Tap Add one, Take away or Clear. This does **not**
  pick an answer, show the correct result, change a score, unlock a star, or count as a hint.
  Controls are native, keyboard accessible 48px targets with a descriptive live count.
- Make completed on-device skill-history writes read-back verified. If browser storage
  is inaccessible or silently ignores writes, preserve a copy **in the active tab**,
  display a truthful warning, and provide Try saving again. Never imply that a
  volatile copy will survive closing the tab, private browsing, or device reset.
- Preserve source and score keys, normal data migrations, offline PWA shell, daily
  teaching, parent materials and test previews. No student information enters Git.
- Mobile screen/browser and offline-storage-failure tests, accessibility, full
  exact-head QA, independent QA, protected merge and live Pages parity are required.
  Physical handset/offline testing is a separate quality observation.
