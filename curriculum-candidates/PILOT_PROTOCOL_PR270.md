# ABVM Reading/ELA PR #270 — optional pilot and automated-release policy

**Current policy as of October 20, 2026:** The owner removed all mandatory human
reviewer, educator-signoff, guardian-signoff, human pilot and separate release-
approval requirements for ABVM. This document is an optional private research
protocol only, **not a prerequisite for curriculum or application publication**.
Older statements requiring a qualified human reviewer or manual promotion are
superseded. Never claim a human reviewed or approved a candidate when none did.

## Content provenance and existing HOLD status

The four Reading/ELA candidate manifests contain 32 original practice questions.
They remain held and disabled by default unless and until they independently
satisfy the existing automated teacher-lineage, answer correctness, semantic
coverage, copyright, privacy, accessibility, quality and exact-source release
checks. A passing synthetic test is not evidence about a real student. Do not
set `enabledByDefault=true` or change a HOLD status merely because human
signoff is no longer required. The ordinary verified teacher and homework
refresh must continue independently while incomplete candidate families stay
isolated.

Run `node scripts/audit-held-curriculum-pilot.mjs` and the relevant curriculum,
source/parity, question, browser and full QA suites. Compare the source-locked
content fingerprint against the exact candidate. Any source or question edit
requires newly passing automated evidence for that exact content version.
The rollout controller may promote only supported, completely verified
families through its existing bounded publication gates. No separate human
review or real-learner experiment may be imposed as a new blocker.

## Optional private feedback and printable kit

The 32-question editorial packet is `REVIEW_PR270.md`. Its checkboxes are
optional feedback and do not authorize or prevent publication.

An optional black-and-white kit can be generated with
`node scripts/build-held-curriculum-pilot-kit.mjs`. Its student sheet, separate
answer key and blank observation form are *not* real learning evidence or
approval. The offline interactive educator preview generated by
`node scripts/build-private-curriculum-pilot.mjs` remains private and must never
be deployed to GitHub Pages or contain learner identifiers.

A real student pilot is **optional**. If ever conducted, use appropriate
guardian permission, secure private records and separate source-locked
consent/evidence; never fabricate observations or treat synthetic totals as
actual learner outcomes. If no pilot takes place, the candidate is judged only
by independently reproducible evidence and the production quality gates.
Unknown or disputed factual claims remain held until verifiable source evidence
exists, not until a particular person provides approval.

## Release boundary

This protocol grants no exception to source verification, source-date
freshness, child privacy, content rights, substantive question accuracy,
offline/mobile/accessibility testing or current-main GitHub Pages acceptance.
The owner's standing authorization permits promotion without human reviewers
**when those automatic gates pass**. Publication is not established by this
document, a draft PR or an untested content fingerprint.
